# Frontend

React + TypeScript + Vite + Tailwind + shadcn/ui.

See the root `README.md` for how to run everything and `docs/CODE_TOUR.md` for what each file does.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to :8000
npm run build    # writes dist/, served by FastAPI in Docker
npm run lint
```
